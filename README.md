# Salary Prediction using Multiple Linear Regression

## Project Overview
This project predicts employee salaries using Machine Learning based on:
- Experience
- Test Score
- Interview Score

The project compares Single Feature and Multiple Feature Linear Regression models and selects the best-performing model.

## Features
- Data Loading using Pandas
- Data Visualization using Matplotlib
- Train-Test Split
- Multiple Linear Regression
- RMSE Evaluation
- R² Score Evaluation
- Model Comparison
- Model Saving using Pickle
- Interactive Salary Prediction

Multiple Feature Model Performance:

- RMSE: 883.54
- R² Score: 0.999

The Multiple Feature Model performed significantly better than the Single Feature Model.
